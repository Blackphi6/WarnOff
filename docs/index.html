WarnOff

信頼できるアプリの「開発元を確認できません」警告を、メニューバーからワンクリックで消す。

ダウンロード (無料) GitHubで見る

できること

自動で監視

選んだフォルダ(デフォルトは /Applications)を見て、隔離属性(quarantine)が付いたファイルを自動で解除します。

対応形式

.app / .dmg / .zip に対応。ダウンロード中のファイルはスキップします。

軽量・メニューバーのみ

Dockを占有しないメニューバーアプリ。ログイン時に自動起動(切替可)。

多言語対応

Macの言語設定に合わせて日本語・英語・簡体字中国語で表示されます。

信頼できるファイル専用です。 隔離属性はダウンロードしたファイルに対するmacOSの安全確認です。見知らぬ提供元のアプリまで解除すると、危険なソフトも警告なしで開けるようになります。自分で入れた・信頼しているアプリだけに使ってください。

インストール

  1. Releases から WarnOff-macOS.zip をダウンロード
  2. 展開して WarnOff.app を /Applications に移動
  3. 初回は Control クリック → 「開く」で起動(Gatekeeperの確認)
  4. メニューバーのシールドアイコンをクリック

ソースからビルド

git clone https://github.com/Blackphi6/WarnOff.git
cd WarnOff
make
make install
